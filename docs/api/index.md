# API reference

Import as `import bifrost as bf`. The top-level names are `bf.StackDevice`, `bf.apply_stack`, `bf.init_stack_params`,
`bf.StackOptions`, `bf.TopRoughness`, `bf.StackDiagnosticWarning`, `bf.record_timings` and `bf.view`; the modules are
`bf.stack`, `bf.geometry`, `bf.subpixel`, `bf.timing` and `bf.viewer`.

For `Component`, cells, routing and PDKs see the
[gdsfactory API reference](https://gdsfactory.github.io/gdsfactory/api/).

- [bf.stack](stack.md)
- [bf.geometry](geometry.md)
- [bf.subpixel and bf.timing](subpixel-timing.md)
- [bf.viewer](viewer.md)
